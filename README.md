# QuickText + Knowledge Lookup

**QuickText + Knowledge Lookup** is a Windows application designed to speed up workflows involving AI, programming, Unreal Engine, and other tasks that require frequent use of text snippets or technical terms.

## Main Features

### QuickText

* Save frequently used text and prompts as snippets.
* Quickly search by name or content.
* Favorites and Recent items.
* Supports multiline text.
* Custom color for each snippet.
* Individual hotkeys for snippets.
* Click to paste directly into the currently active application.
* Preserves and restores the clipboard after pasting.

### Knowledge Lookup

* Save technical concepts and personal notes.
* Supports Name, Aliases, Category, Description, and Tags.
* Create custom Properties for each concept.
* Search across all stored content.
* Fuzzy Search helps find concepts even when you do not remember the exact name.
* Custom colors for each Knowledge Entry and Property.
* Customize font, font size, bold, italic, underline, and reading appearance.

## Select + Hotkey

This is one of the most important features of Knowledge Lookup.

When no text is selected:

Hotkey
→ QuickText Palette

When a term is selected and copied:

Select text
→ Copy
→ Knowledge Lookup

The application automatically uses the selected text as the search keyword.

This means that when you encounter a concept you have forgotten, you do not need to manually open the application and type the keyword again.

## Custom Properties

Knowledge Entries are not limited to a fixed form.

Users can add custom fields such as:

* Where to Find
* When to Use
* Example
* Related Concepts
* Common Mistakes
* Project Notes
* or any other custom Property.

## Shared Color System

QuickText and Knowledge Lookup use the same color system.

Saved colors can be used for:

* Snippets
* Knowledge Entries
* Properties
* Reading Appearance

The Color Picker supports Saved Colors and HEX color customization.

## Global Hotkey

The application runs in the background on Windows and supports global hotkeys.

A single main hotkey can automatically decide whether to:

* open QuickText when there is no selection;
* open Knowledge Lookup when text is selected.

Snippets can also have their own individual hotkeys for direct pasting.

## Goal

The core idea of the application is:

**Things you type repeatedly → save them for quick insertion.**

**Things you often forget → save them for quick lookup.**
